Selected system-design case studies

1. HCAF — Healthcare Composition & AI Framework (SpinSci)

Problem → multi-vendor EHR/CCaaS projects took 8–9 months per client · Approach → modular connector + workflow + AI config layer · Result → 3–4 week delivery

Design: Treat each EHR (Epic/Athena/Cerner) and CCaaS (Five9/WxCC/8x8/Zoom/NiceCX) as swappable adapters behind a common domain API; compose custom clinical/ops flows (scheduling, paging, workforce) via Everbridge, WCTP, QGenda, Kyruus, Workday, etc. AI assists mapping, scaffolding, and deployment checks so teams reuse 70%+ of a proven composition instead of rebuilding. Operator Console sits as the human control plane over live patient/call context with secure service boundaries and auditability.

2. Emoneeds AI ops + ScanPsy + Wellbeing Plus

Problem → fragmented care ops & slow psych assessments · Approach → ERP/CRM + AI monitoring + Terra · Result → minutes-level assessment; enterprise wellbeing adoption

Design: Event-oriented patient timeline (clinical notes, appointments, wearable/health signals via Terra) feeding AI monitors for professionals; ScanPsy as a bounded assessment microservice with scoring pipelines and report generation; Wellbeing Plus as multi-tenant B2B portal with RBAC, SSO-ready patterns, and AWS CI/CD for weekly releases.
