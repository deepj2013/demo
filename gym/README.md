# Adiyogi Fitness Studio — Digital Demo

Client pitch demo for **Adiyogi Fitness Studio** (आदियोगी फिटनेस स्टूडियो), Khargone, MP.

## How to open

Open `index.html` in a browser (double-click or drag into Chrome/Safari).

Or from Terminal:

```bash
cd "/Volumes/Data/Adiyogi fitnessStudio"
python3 -m http.server 8080
```

Then visit: http://localhost:8080
