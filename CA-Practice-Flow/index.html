Brief

Replace Excel/WhatsApp tracking with a centralized, event-driven practice OS. Automate repetitive compliance work; keep professional judgment and final approvals under CA control.

How we deliver it

  • Single platform for clients, services, workflows, documents, comms, billing, and dashboards.
  • Event + calendar engine that creates work automatically (due dates, uploads, Tally sync, notice ingest).
  • Exception engine so humans only touch Amber/Red items.
  • Hard CA gates on filing, notice replies, write-offs, and high-value judgments — AI never files unsupervised.
Operating model: Client Input → AI/OCR/API → Validation → Automation → Exception → Staff/CA Review → Filing → Archive → Billing → Next Cycle.

Brief

We do not rip-and-replace overnight. We wrap TallyPrime, upgrade communication channels, and retire Excel trackers after the pilot proves metrics.

How each tool maps

  • TallyPrime → Integration layer (XML/ODBC/API bridge) for ledgers, vouchers, GST data import/export.
  • Excel calendars → Workflow Engine Service Master + compliance calendar (Excel becomes export-only reporting).
  • WhatsApp → WhatsApp Business API with approved templates (doc request, reminder, approval, filing, payment).
  • Email → Inbound parse for notices + outbound branded notifications; attachments land in DMS.
  • Manual GST/TDS/ITR/Audit/DSC/Billing → Configurable workflows with checklists, OCR, and exception queues.
Migration rule: Pilot 30–50 clients on parallel run; Excel remains fallback until automation % and error metrics clear thresholds.

Brief

Automation is the default path. Staff work from queues; they do not monitor 400 clients manually.

Automated behaviors (built-in)

  • Create tasks from events & statutory deadlines
  • Request missing documents (portal + WhatsApp + email)
  • Send scheduled reminders (D−7, D−3, D−1, overdue ladder)
  • Flag incomplete / incorrect documents (checklist + AI validation)
  • Extract data via OCR/AI into structured fields
  • Reconcile Tally ↔ portal data where rules allow
  • Identify exceptions & anomalies (thresholds configurable)
  • Escalate overdue items (Staff → Senior → CA)
  • Generate client notifications on status change
  • Store filing acknowledgements in DMS
  • Generate recurring invoices & track payments
  • Spawn the next compliance cycle on archive
Staff day: Open Staff Dashboard → clear Amber queue → request CA only when Red. No spreadsheet hunting.

Brief

Mandatory controls from day one — not a phase-2 afterthought. AI assists; it never files or gives uncontrolled professional advice.

  • Role-based access (CA Partner, Staff, Client, Admin)
  • Client-level permissions (staff assigned to client sets)
  • MFA for all internal users
  • Encryption in transit (TLS) & at rest
  • Immutable audit logs
  • Automated encrypted backups + restore drills
  • Document ACLs (view/download logged)
  • User activity tracking
  • CA approval gates for high-risk actions (filing, notice reply, write-off, material exception clear)
  • Policy: No uncontrolled AI-generated filing or advice
Demo: Admin → Security panel shows roles, MFA policy, and audit log viewer.
